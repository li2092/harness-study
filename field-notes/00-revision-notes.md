# 修订记录

本卷 2026 年 9 月修订。读过 0902 版的读者，可以从这一章了解改了哪里。

## 修订范围与原则

这次修订对照一手资料核查了书中引用的外部事实，统一了三卷的术语，修正了几处前后矛盾，并按"让第一次读的人也读得懂"的标准重写了部分段落。书的观点、结构和案例都没有变。

三卷共用的术语约定与外部事实的核查结论，见仓库根目录的 [`术语对照表.md`](../术语对照表.md)。

## 结论与建议有变化的地方

- **8.2 恢复 system prompt**：旧版一处说"用当前版本替换"，另一处说"按崩溃前的版本恢复"，前后矛盾。修订后拆成两部分：环境信息与系统约束按当前版本重新生成；塑形内容（few-shot 示例、输出格式、流程模板）按崩溃前的版本恢复。与第二卷 §10.8 一致。
- **11.3 单次执行的副作用**：旧版标题主张"加执行守卫"，正文却说标志位守卫是错误做法。修订后标题与正文统一为：写清理函数，让副作用经得起重复执行；只有整个应用只执行一次的初始化才用一次性标志位。
- **2.1、2.2 内容敷衍的归因**：旧版把"格式合法、内容敷衍"算作输出上限设小的后果。修订后，输出上限只会造成硬截断；内容敷衍与提前收尾的成因是模型看得见的预算信号和上下文长度，与输出上限、步数上限无关。
- **3.9 大结果的处理**：旧版第一级写的是"截断"，与 2.3 "不要直接截断"冲突。修订后改为全文外置，上下文里放摘要加取回标识。
- **12.7、13.4 测试集**：补充开发集与留出集的区分：日常调参只看开发集，留出集只在上线前跑一次；线上失败登记为判例后回流用例库，用来防止对固定测试集过拟合。
- **4.4、4.5 大小写**：写明分界：值的大小写可以容错，字段名的大小写不容错，按拼错处理。

## 术语调整

| 旧版 | 修订后 |
|---|---|
| 断路 / 断路器 | 强制换路；借用熔断器（circuit breaker）的说法时注明只有"打开"这一步 |
| 同步函数 | 状态切换函数 |
| 制表符（指框线字符） | 框线字符 |
| 写权、结算、落终态 | 写入许可、登记结果、标记为已结束 |
| 副作用租约、提交点 | 保留，首次出现注明：租约没有过期时间，按运行状态撤销，作用近似围栏令牌（fencing token）；提交点指副作用发出前的最后一刻，在此复核授权以消除 TOCTOU 窗口 |
| 写越界 | 路径穿越（path traversal），解包场景称 Zip Slip |
| 留一法 | 留一消融（leave-one-out ablation） |
| 协同 / 拮抗 / 冗余 / 互相替代 | 正交互（协同）/ 负交互；负交互分冗余与干扰 |
| 分辨力下限 | 最小可检测效应（MDE） |
| 真空通过 | 空真式通过（vacuous pass） |
| 代码签名 | 代码指纹；整组记录称溯源信息 |
| 验证三件套、两轮断路、完成分级 | 展开为具体做法 |
| 把脉 | 行为探测（书中也称"把脉"） |
| 轮 | 一次模型调用加其工具执行；从一条用户消息到最终回复称"回合" |
| 历史 / 投影 / 视图 | 历史指持久化的完整记录；上下文指每一轮由历史派生、实际发给模型的那一份 |
| 本册、前两册 | 本卷、前两卷 |

此外，首次出现的业界术语补上了通用名，例如 TOCTOU、X-Forwarded-For、`NO_PROXY`、`tool_choice`、SIGHUP / setsid、React StrictMode、fail-open / fail-closed、影子模式、at-least-once、tool poisoning / rug pull / tool shadowing。
