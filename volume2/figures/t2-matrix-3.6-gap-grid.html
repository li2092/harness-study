落格结果本身就是一个发现

六行里四行最先失守于"看得见吗"。这套系统的结构底色是证据极度稀薄——绝大多数缺口在被追问"管得住吗"之前，先倒在根本看不见上。只有两行例外：交互契约先失守在"扰动下稳吗"（断开这个扰动把投影推离真相），权限契约先失守在"管得住吗"（容器去向没有干预点）。最后一行整行是空的——一个连"发生过什么"都记不下来的系统，谈不上"改进有没有数据"。

两套"缺口"不是同一套编号

3.1 节说的缺口一、二、三是三个代码级根因（导航逃逸／读库读到 run 开始前／抢占后跳过落库）；这张图上的六个是契约级缺口，一份契约一个。三个代码缺口串成一次丢失，六个契约缺口是它在坐标系上的投影——数目对不上是正常的。

压缩语的完整反面教材

第一章那句压缩语——每个状态有归宿，每个故障有路径，每个中断可恢复或诚实终结——在这里三条全违：M5 在五个载体间漂流，没有一处算数；R1 从 running 到消失，没有一行记录解释它；被打断的一轮悬在"既没完成也没终结"的暗区，无声蒸发。
