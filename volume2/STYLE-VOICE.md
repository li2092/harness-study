# 第二卷语体基准（STYLE-VOICE）· 文风统一工程

> 用途：把用户亲笔段落的语体提炼成可执行画像，由 AI 应用到未亲笔精修的章节。随用户每次亲笔修订升版。
> 工作流（用户 2026-07-27 定）：**用户亲笔精修若干章 → AI 拿基准提交做 git diff、只看用户改动、升版画像 → AI 按新画像逐章优化其余章 → 用户逐章终审**。文风终审权在用户；AI 交付按章分批，不一次铺全卷。

## 画像 v1（依据：用户 2026-07-27 亲笔重写 1.0 开场四段）

样本位置：`01-architecture-v4.0.md` 1.0 节开头四段（"在 Harness Study 入门卷里我们主要展示了…"起）。

四条：

1. **叙述者站位**：作者用"我们"（我们展示了／我们总结了），读者称"大家／读者／有的读者"，允许第一人称代入（"我的智能体"）。不用命令式开场（原"先把位置摆正"被删即是信号）。
2. **宣告腔改解释腔**："本卷叫 X"→"我们总结了 X，X 可以理解为…"；强断言降温（"那一卷讲完了"→"有了一定的概念"）。
3. **读者动作路径写进正文，允许设问**：先打补丁、改几十版提示词"好像提升也不大？"——把读者真实会做的事和心理反应铺在论点前面。
4. **技术论证原样**：数字、案例细节、论证句用户几乎逐字保留——画像只管站位与衔接，不管内容。

## 硬约束（应用画像时不许破）

- **粗体锚句逐字保留**（被后续章节逐字引用）：如"每个状态有归宿，每个故障有路径，每个中断可恢复或诚实终结""检查器信任了被检查者递上来的内部信号""同一种语义实现了 N 份，就会漂移成 N 种"、假落地公式、反格言等。粗体一律不动。
- **R1 红线仍有效**："你"系不新增（既有问句钩子除外）；不引入"让我们／本章将／综上所述"；模糊词（显著／大量／很多）禁用；"而不是／不仅…还"禁用。
- 【】证据标注、图引用、工作制品引用、章节引用一字不动。
- 每段只调站位句、衔接、称呼；不重写论证、不增删事实。
