### 来源 B · Agent-Z 写作 skill（`/Users/jimi/ClaudeCode/Agent-Z/docs/learn-harness/_methodology/`，v6，四轮否决迭代产物）
写每章前重读 `chapter-writing-skill.md` §1/§5/§11/§13 + `voice-references.md` §一/§七/§八。核心吸收：

1. **七条铁律**：不用"你"开头；第一句就是判断/观察/故事；不元叙述（"本章将/接下来让我们"）；过渡靠因果连词；收尾在动作；数字优先于形容词；引用给文件路径。
2. **钱学森八姿态**（中文主稿）：先立坐标；术语升格+"即"下定义（30 字内无形容词）；抽象名词拆构成；数字切刀；先承认旧前提崩了再推新方法；动词序列优于名词抽象；诊断在前症状在后；强论断挂"我看/我的判断是"软引信。
3. **★对比修辞红线**（v5.5 三次否决的根因）：`不是X，是Y / 而不是 / 不仅…还 / 不只是…更是` 整章 ≤2 处；替代法=直接写 Y 删 X，或断成两句"过去假设 X。实际上 Y。"
4. **演化四拍**（机制叙事）：早期怎么做 → 踩到什么痛 → 业界演化出什么 → 现在的成熟契约与不做的代价。
5. **立论/来源标签嵌段中或段末，不抢段首**；段首必须是论断/观察/故事。
6. **标题规则**：章名允许比喻（吴军腔），节名 8-18 字冷静短语（许式伟腔），子节最短名词短语；标题里数字用汉字；"你"只出现在问句钩子；`：`与`—`不堆叠。
7. **章末三件**：破坏实验（大纲模板已含）＋"立即可做的一个动作（5 分钟）"＋三轮审稿日志。不用总结型收尾。
8. **表格只做信息浓缩**，放在故事讲完之后，不替代叙事；教学价值=读者的 aha，不是信息密度。

### 三轮审稿协议（每章必跑，通过才交付）

- **R0 归属检查（2026-07-19 加，三章审回的根因）**：逐段标注挂载的推理链节点（对照该章 spec），孤儿段＝0；SPEC.md 三条硬规则逐条跑——连接词测试（相邻节点间能填"因为/所以/但是/否则"）、结构出场规则（结构名词首现前必有迫使它存在的问题）、素材配额（节点主证据 ≤1、正文表格 ≤3）。
- **R1 grep 红线**（命中即改，不进 R2）：
```bash
grep -n "你的\|你应该\|你做过\|你会发现" ch.md              # =0
grep -n "在这个\|让我们\|接下来让\|综上所述\|总而言之" ch.md  # =0
grep -n "这一章不\|本章将\|本节将" ch.md                    # =0
grep -n "显著\|大量\|很多" ch.md                            # ≤3
grep -n "不是.*[，,].*是\|而不是\|不仅.*[，,].*还\|不只是.*[，,].*更是" ch.md  # ≤2
grep -nE "^#+ .{25,}" ch.md                                # 标题超长 =0
grep -nE "^#+ .*[0-9]+ ?(个|类|种|项|条|步)" ch.md          # ≤1
```
- **R1.5 开篇结构检查**（2026-07-17 加，§一开头三次返工的根因，grep 量不出）：第一个具体场景（带时间/人物/文件/数字的叙事）出现之前，未绑定所指的术语与专名 ≤5 个；顿号/分号连缀 ≥4 项的清单段 ≤1 段；章节路线图、分类名单等抽象枚举，不得先于给它们所指的素材出现——宁可悬置（"名字先不报"），不可预支。教训出处：读者在拿到所指之前被要求空背标签，就是"心累"的机制；红线全过 ≠ 阅读负担合格。
- **R2 姿态对照**：voice-references §一逐条对每节找"形似神不似"段重写。
- **R3 冷读模拟**：隔段时间再读；每段问"senior 工程师第一次读会合上电脑吗 / 有 LLM 味吗 / 记住了什么具体的事"；找三段最别扭的重写，回 R1 重跑。
- 章末附《三轮审稿日志》记录各轮命中与修改。
